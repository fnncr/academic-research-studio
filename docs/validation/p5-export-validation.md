# Протокол проверки P5

Ветка `feat/p5-docx-export`, основание main после PR #9 (`1462aba`).

- Backend: 202 теста прошли на PostgreSQL 17 в изолированных схемах; новый модуль экспорта — 13 тестов. В том числе Alembic command.check и повтор upgrade head, проверки старых P2–P4. Одновременные экспорты разных проектов не смешивают текст и нумерацию. Новых миграций нет.
- Frontend: 36 тестов прошли, включая 5 сценариев экрана экспорта и интеграцию с редактором P2.
- TypeScript/Vite build и git diff --check прошли.
- Единственное backend-предупреждение: существующий Starlette TestClient/httpx deprecation; новые зависимости не добавлены.
- Проверена побайтовая идентичность двух экспортов и сохранение идентичного файла после добавления новой версии метаданных публикации: используется старая SourceVersion.
- Проверены смешанные citations в абзаце, списке и ячейке таблицы, две SourceVersion одной публикации, UTF-16 с символом вне BMP, отсутствие повторных записей библиографии для одной версии.
- Неполные метаданные, неизвестные/чужие версии, повреждённые структуры и citation ranges, устаревший план, незаполненный титул, placeholder и изменение параметров после preflight блокируют экспорт.

Два синтетических DOCX открыты LibreOfficeDev 26.8.0.0.alpha0 и преобразованы в PDF. Визуально просмотрены титульный лист с колонтитулами/страницей и основной текст с таблицей и библиографией. Явных обрезаний, наложений и повреждения кириллицы не обнаружено. PDF содержит ожидаемые 2 страницы у примера без титула и 3 у примера с титулом/оглавлением. Временные файлы использовались только в рабочем каталоге; пользовательских документов не было.

`fc-match 'Times New Roman'` выбрал Liberation Serif. Поэтому эта проверка подтверждает открытие OOXML и отсутствие явных дефектов на примерах, но не идентичность Microsoft Word, Times New Roman и официальному шаблону. Начальное поле TOC содержит заголовки без страниц; полное оглавление нужно обновить в Word. Визуальная проверка длинных реальных таблиц, конкретного университетского образца и установленного TNR остаётся приёмкой владельца.
