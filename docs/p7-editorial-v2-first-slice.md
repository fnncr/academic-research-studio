# P7 — Editorial Review v2: первый исполняемый этап

Статус: экспериментальный редакторский модуль. Он не определяет происхождение текста от ИИ и не имитирует проценты «Антиплагиат.РФ» или «Антиплагиат.ВУЗ». Ни один из 14 новых пунктов не объявляется параметром закрытого детектора.

## Реализовано

- Исходный реестр 01–34 (v1) не изменён.
- Отдельный версионированный каталог новых кандидатов 35–48.
- Две ограниченные лексические диагностики: 35 (похожая формулировка в близких абзацах) и 42 (похожая формулировка через несколько абзацев).
- Каждый кандидат имеет block UUID, UTF-16 диапазон, точную цитату, хеш, связанный абзац и версию правила.
- Read-only owner API: GET /api/projects/{project_id}/editorial/revisions/{revision_id}/preview с заголовком Authorization Bearer MODEL_OWNER_TOKEN.
- Просмотр результатов сохранённой версии в редакторе; черновик не меняется.
- Нет внешних вызовов или новых миграций. Остальные 12 критериев показывают insufficient_data, а не ложное no_issue.

Ограничение: проверяются только достаточно длинные предложения обычных параграфов. Цитаты, изображения, таблицы, формулы, сноски, списки, библиография и другие объекты не являются частью оцениваемого покрытия. Лексический кандидат не является доказательством смыслового дублирования: требуется ручное чтение контекста.

## Дальнейший порядок работы

Сначала завершить формальные P7-критерии по исходным группам (источники, структура, повторение). Затем сделать отдельные семантические проверки 35–48 с явными статусами неопределённости. Исходные 34 критерия не изменять без согласованной новой версии. Не смешивать редакторские правила с будущими научными SQ01–SQ10.

Если появится официальный лицензированный доступ к «Антиплагиату», изучить разрешённые API и коллекции. Оригинальность, цитирование и ИИ-атрибуция — разные метрики. Без такого API нельзя воспроизвести внутренний процент сервиса.

## Валидация

Для каждой диагностики собрать набор документов с правами на использование, независимой ручной разметкой, RU/EN и разными академическими жанрами. Оценивать precision/recall/F1 по фрагментам, false-positive rate для человеческих контрольных работ и согласованность экспертов. Разделять авторов между обучающей, настроечной и тестовой выборками. Сравнение с официальными отчётами проводить только при законном доступе, фиксируя дату, тариф, модель и набор коллекций. Не учить модуль манипулировать оценкой ИИ-авторства.

## Безопасность

Репозиторий рассчитан на single-owner установку. Все личные P2–P5 API должны оставаться на loopback или за аутентифицированным TLS proxy. MODEL_OWNER_TOKEN не реализует многопользовательскую авторизацию.

Новый endpoint только читает историческую версию и вычисляет временный отчёт, не меняет PostgreSQL, исходные рукописи или DOCX. Сохранение ReviewRun/Finding в БД потребуется отдельным этапом с аддитивной миграцией.

Выполнение автоматических тестов и CI должно быть зафиксировано отдельно. Ручная проверка на корпусе и официальный анализ «Антиплагиата» не входят в текущий первый этап.
